ISMO-SkillSwap
Project Overview
ISMO-SkillSwap is a web-based skills-sharing platform designed to connect learners, trainers, and mentors. It allows users to share their knowledge, exchange skills, request assistance, and develop their professional abilities.

The platform provides different interfaces for trainees, trainers, mentors, and administrators.
Main Features
- User Management: Manage platform users and their accounts.
- Skills Management: Add, update, and manage skills.
- Marketplace: Share skills, offer assistance, and request help.
- Badges: Reward users for their participation and achievements.
- Ranking System: Display user rankings.
- Passport: Generate and manage skill passports.
- Promotion Management: Handle promotion requests.
- Administration: Manage users, badges, and reported content.

Installation and Setup
1. Clone the repository.
2. Copy the project folder into the XAMPP htdocs directory.
3. Start Apache and MySQL from XAMPP.
4. Create a MySQL database named skillswap.
5. Import the schema.sql file into the database using phpMyAdmin.
6. Check the database connection settings in dbopen/db.php.
7. Open the project in your browser through localhost.
